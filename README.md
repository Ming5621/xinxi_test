# 微机教室在线考试系统

面向微机教室局域网环境的在线考试系统。教师机在教室中作为服务器，学生机通过浏览器登录答题。

## 下载 Windows 版（推荐）

无需安装 Python / Node.js，解压后双击即可使用。

**[⬇️ 点击下载 ExamSystem.zip（内含 ExamSystem.exe）](https://github.com/Ming5621/xinxi_test/releases/latest/download/ExamSystem.zip)**

- 最新版本发布页：[Releases](https://github.com/Ming5621/xinxi_test/releases/latest)
- 使用步骤：解压 zip → 双击 `ExamSystem.exe`（保持窗口不关）
- 程序会自动选择空闲端口（优先 `18765`），放行防火墙，并自动打开浏览器
- 本机/学生机地址以启动器窗口显示为准（例如 `http://127.0.0.1:18765`）
- 若启动失败，请查看 `%APPDATA%\微机教室考试系统\launcher.log` 与 `server.log`

## 功能特性

- **题型支持**：选择题、判断题
- **学生端**：登录、在线答题（倒计时）、查看个人成绩与答题详情
- **教师端**：学生管理、考试管理（自定义题目）、发布/结束考试
- **管理员**：账号管理（查看并维护全部教师、学生账号：新建、改名、改用户名、分配班级、重置密码、启用/禁用、删除）
- **成绩查询**：教师查看全班成绩，学生查看个人成绩
- **自动统计**：考试结束后自动批改并生成统计分析（平均分、及格率、分数段分布、各题正确率）
- **精美界面**：Vue 3 + Element Plus 现代化 UI

## 技术栈

| 层级 | 技术 |
|------|------|
| 后端 | Python FastAPI + SQLAlchemy |
| 数据库 | SQLite（无需额外安装） |
| 前端 | Vue 3 + Vite + Element Plus + Pinia |
| 认证 | JWT Token |

## 快速开始（开发模式）

### 环境要求

- Python 3.10+
- Node.js 18+（仅构建前端时需要）

### 一键启动

```bash
# 1. 安装后端依赖
pip install -r backend/requirements.txt

# 2. 构建前端
cd frontend && npm install && npm run build && cd ..

# 3. 启动服务器（教师机运行）
python run.py
```

启动后终端会显示访问地址：
- 教师机本地：`http://localhost:8000`
- 学生机访问：`http://<教师机IP>:8000`

### 登录说明

| 角色 | 方式 |
|------|------|
| 学生 | 登录页选择「学生」，**输入姓名即可进入**（无需预设账号） |
| 教师 | `teacher1` ~ `teacher4`，密码均为 `teacher123` |
| 管理员 | `admin` / `admin123`（可选） |

教师登录后可在控制台查看当前在线学生，并发布考试或发起课堂打字测试。

管理员登录后进入「账号管理」，可维护系统中的教师和学生账号（含姓名登录自动生成的学生）。不能删除或禁用当前管理员，也不能再创建新的管理员账号。学生仍在登录页输入姓名进入。

## 使用流程

### 管理员操作

1. 使用 `admin` / `admin123` 登录，进入「账号管理」
2. 可按角色筛选，查看管理员、教师和学生（含姓名、用户名、班级）
3. 可添加教师或学生，编辑姓名、用户名、班级，为教师重置密码，或启用、禁用、删除账号
4. 当前管理员不能被删除或禁用，也不能把其他账号升为管理员

### 教师操作

1. 使用 `teacher1`～`teacher4` 登录（密码均为 `teacher123`）
2. 在控制台查看已用姓名登录的在线学生，并发布考试或发起课堂打字测试
3. 在「考试管理」→「创建考试」中自定义题目（选择题/判断题/打字题），支持**批量导入题目**
4. 点击「发布」开放考试；学生端输入姓名即可作答
5. 考试结束后点击「结束」，系统自动批改并统计
6. 在「学生动态」查看全部已登录学生（含离线）

### 批量导入（可选）

如需预先录入学生，可使用「学生动态」中的批量导入：

```csv
用户名,姓名,班级,密码
stu_zhang,张三,课堂,123456
stu_li,李四,课堂,
```
班级请填写教师所管班级（默认「课堂」）。密码留空时使用默认密码（123456）。

**题目导入格式一（CSV，适合 Excel 编辑）：**
```csv
类型,题目,选项A,选项B,选项C,选项D,答案,分值
choice,以下哪个是CPU,内存,CPU,硬盘,显卡,B,10
judge,RAM断电后数据不丢失,,,,,错误,10
```

**题目导入格式二（块格式，适合直接粘贴）：**
```
[选择] 以下哪个是CPU？
A. 内存
B. CPU
C. 硬盘
D. 显卡
答案：B
分值：10

[判断] RAM断电后数据不丢失。
答案：错误
分值：10
```

### 学生操作

1. 登录页输入姓名进入（自动进入「课堂」班级）
2. 在「考试大厅」选择进行中的考试
3. 答题并提交（时间到自动提交）
4. 在「我的成绩」查看分数和答题详情
5. 在「打字练习」进行日常打字训练（不限次数）

### 账号与数据关系

- **学生登录**：无需预设账号，姓名登录后自动创建学生记录（班级默认「课堂」）。
- **教师 ↔ 学生**：四个教师账号均管理「课堂」班级，可查看姓名登录进来的在线学生并发任务。
- **练习素材 ↔ 教师**：打字练习文章绑定到创建教师账号（`teacher_id`）。
- **考试 ↔ 教师**：考试有 `created_by` 指向创建教师。

### 打字考核标准

参考中考信息技术及义务教育信息科技课标：

| 等级 | 速度要求 | 说明 |
|------|----------|------|
| 达标 | ≥ 10 字/分钟 | 中考信息技术基本要求 |
| 良好 | ≥ 20 字/分钟 | 高于中考要求 |
| 优秀 | ≥ 30 字/分钟 | 课标第三学段基础达标 |
| 卓越 | ≥ 40 字/分钟 | 远超课标要求 |

准确率要求 ≥ 95%。低于该准确率时不授予「良好」「优秀」「卓越」；速度达到 10 字/分钟仍记为「达标」，否则为「未达标」。

## 开发模式

前后端分离开发：

```bash
# 终端 1：启动后端
cd backend && uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 终端 2：启动前端开发服务器
cd frontend && npm run dev
```

前端开发服务器会自动代理 API 请求到后端。

## 演示录制

启动服务后，可用 Playwright 自动录制使用演示视频或截图：

```bash
# 安装演示依赖（仅需一次）
npm install

# 录制使用演示视频（输出到 /opt/cursor/artifacts/videos/）
npm run demo:video

# 批量截取界面截图
npm run demo:screenshots
```

演示视频涵盖：登录页 → 教师端（学生管理、考试管理、统计）→ 学生端（考试大厅、打字练习、我的成绩）。

## 局域网部署说明

1. 确保教师机防火墙允许 8000 端口入站
2. 学生机浏览器访问 `http://教师机IP:8000`
3. 所有数据存储在教师机的 `backend/exam_system.db` 文件中
