# Windows 打包说明

将考试系统打包为 Windows 可执行程序，教师机双击即可运行，无需安装 Python 或 Node.js。

## 教师机使用（已打包）

1. 解压 `微机教室考试系统.zip`（或运行安装程序）
2. 双击 **`ExamSystem.exe`**
3. 浏览器自动打开，学生机访问窗口中显示的 IP 地址
4. 关闭黑色命令行窗口即停止服务

**数据存储位置**：`%APPDATA%\微机教室考试系统\exam_system.db`

---

## 开发者打包步骤

### 环境要求

- Windows 10/11（64位）
- Python 3.10+
- Node.js 18+

### 一键打包

```bat
packaging\build_windows.bat
```

完成后输出：
- `dist\微机教室考试系统\ExamSystem.exe` — 可运行程序
- `release\微机教室考试系统.zip` — 分发压缩包

### 制作安装程序（可选）

1. 安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)
2. 运行：

```bat
packaging\build_installer.bat
```

生成：`release\ExamSystem-Setup.exe`

v1.2.18 起安装向导会在安装前展示版权信息（版权所有 © 柴延明，保留所有权利），EXE 文件属性也包含版权声明。版权文字维护于 `packaging/copyright.txt`，须保留 UTF-8 BOM 编码。

## 局域网部署

1. 教师机运行 `ExamSystem.exe`
2. 记下窗口中的 **学生机访问地址**（如 `http://192.168.1.100:8000`）
3. 确保 Windows 防火墙允许 8000 端口：
   - 控制面板 → Windows 防火墙 → 高级设置 → 入站规则 → 新建规则 → 端口 8000 TCP
4. 学生机浏览器输入上述地址即可

## 常见问题

**Q: 弹窗「端口 18765 服务未能启动」，日志里有 `No time zone found with key Asia/Shanghai`？**  
请改用 **v1.2.11** 及以上。精简版 Windows 没有 IANA 时区库时，旧版会在启动服务时直接退出。这一版自带时区数据，找不到时按 UTC+8 继续启动。窗口底部应显示版本号。

**Q: 教师换教室后学生名单、考试对不上？**  
管理员在「账号管理」导出全部数据，或教师在「学生动态」导出教师数据，到另一台电脑导入。导入前会要求确认，确认后覆盖该账号或该教师在本机的旧数据。

**Q: 卡在「正在启动服务」，等待时间停在 0 秒？**  
请改用 **v1.2.10** 及以上的压缩包再双击 `ExamSystem.exe`。v1.2.10 起等待秒数由主线程刷新，健康检查直连 `127.0.0.1`。更旧的版本会停在「已等待 0s / 75s」，「打开浏览器」也一直是灰色。  
v1.2.7 起端口探测改为先检查空闲再短超时健康检查，冷启动使用预计算密码哈希。默认端口为 `18765`，服务在独立进程中启动。  
仍失败时查看：
1. `%APPDATA%\微机教室考试系统\launcher.log`（里面有 `health wait` 记录）
2. `%APPDATA%\微机教室考试系统\server.log`
3. 以管理员身份运行一次（便于自动放行防火墙）

**Q: 浏览器显示拒绝连接？**  
使用启动器窗口显示的地址（一般为 `http://127.0.0.1:18765`），不要写死 8000。

**Q: 双击 exe 闪退？**  
以管理员身份运行，或检查是否被杀毒软件拦截。查看同上日志文件。

**Q: 学生机无法访问？**  
确认学生机与教师机同一局域网；启动器会尝试自动放行防火墙。仍不通时手动放行窗口中显示的 TCP 端口。

**Q: 如何备份数据？**  
复制 `%APPDATA%\微机教室考试系统\exam_system.db` 即可。

**Q: 如何指定端口？**  
设置环境变量 `EXAM_PORT=18765` 后启动；若该端口被占用会自动改用其它空闲端口。


## v1.2.19 升级时保留或清空数据

直接运行新版安装包即可，无需手动卸载旧版本。安装向导检测旧版本和残留数据后，默认选择「保留全部数据并升级」。保留范围为本机各 Windows 用户的数据目录，包含整个数据库（所有账号、班级、试题、答卷、成绩、打字文章和记录）及附属文件。

安装器先停止程序，将完整数据目录复制到 `%ProgramData%\ExamSystemUpgradeBackups\时间戳`，逐文件校验 SHA-256，成功后才卸载旧程序。旧版卸载器即使删除了数据，安装器也会在安装新文件之前恢复并核验。新版卸载器支持 `/PRESERVEDATA=1`，对未变化的数据文件不做覆盖。备份仅管理员和 SYSTEM 可访问；升级完成后仍保留，确认数据正常后可手动清理。

选择「清空全部旧数据，重新安装」需要再次确认，会清空所有用户的系统数据目录。首次运行会初始化默认账号和示例数据。以前的升级备份不属于活动数据库，不会随此选项删除。

无人值守安装默认保留数据：`ExamSystem-Setup.exe /VERYSILENT /DATA=keep`。仅明确需要重置时使用 `/DATA=reset`。新卸载器静默卸载默认保留数据，仅 `/DELETEDATA=1` 明确清除；升级使用的 `/PRESERVEDATA=1` 优先保留。

备份、卸载或恢复失败时安装会停止并显示错误，已有备份不会被清除。若安装被断电中断，可由管理员使用原安装包内的 `upgrade_data.ps1 -Mode restore -BackupRoot "备份目录"` 恢复快照，或联系维护人员恢复；不要在数据未恢复时启动系统录入新内容。该升级流程无法恢复此前已经删除且没有备份的数据库。
